# Superpowers Rule

When handling development, feature implementation, refactoring, or debugging:
- Follow disciplined engineering practices from `superpowers`.
- Invoke relevant skills (`brainstorming`, `test-driven-development`, `systematic-debugging`, `verification-before-completion`) before writing code.
- Always verify changes with unit tests or automated builds prior to declaring work complete.
- Follow tool mappings specified in `skills/using-superpowers/references/antigravity-tools.md` for Antigravity.
